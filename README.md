# Trading Journal — V1

A focused web trading journal inspired by modern trading journals. It currently runs entirely in the browser with seed data and local component state.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## V1 included
- Dashboard with core trading metrics
- Trade log with search and filters UI
- Trade detail / new trade modal
- Calendar P&L view
- Analytics by setup, instrument, side and strategy
- Responsive dark interface

## Next production step
Connect authentication + PostgreSQL (or Supabase), then persist trades, screenshots and user accounts in the cloud. This keeps the same UI while making it accessible from anywhere.
